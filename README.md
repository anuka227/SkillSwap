# SkillSwap платформ

SkillSwap нь оюутан болон багш, суралцагч болон мэдлэг хуваалцагчдыг холбож, харилцан мэдлэг, ур чадвараа солилцох боломжийг бүрдүүлсэн веб платформ юм. Энэхүү платформын үндсэн зорилго нь хэрэглэгч өөрийн эзэмшдэг ур чадвараа бусдад заахын зэрэгцээ өөрт хэрэгтэй ур чадварыг бусад хэрэглэгчээс суралцах боломжийг олгоход оршино.

Платформд хэрэглэгч бүр өөрийн профайл үүсгэж, эзэмшдэг болон сурахыг хүсэж буй ур чадвараа бүртгүүлэх боломжтой. Мөн ур чадварыг ангилал болон үнэлгээгээр хайж, өөрт тохирох хэрэглэгчийг сонгон сургалт, уулзалтын хүсэлт илгээж болно.

SkillSwap нь хэрэглэгчдийн хоорондын сургалтын session-ийг зохион байгуулах, хүсэлтийг зөвшөөрөх эсвэл татгалзах, уулзалтын үеэр check-in хийх, session дууссаны дараа үнэлгээ өгөх зэрэг үйлдлийг дэмждэг. Мөн хэрэглэгчид session-тэй холбоотой мессеж солилцож, шаардлагатай тохиолдолд асуудал болон зөрчлийг мэдээлэх боломжтой.

Платформд хэрэглэгчийн оролцоог дэмжих зорилгоор credit систем ашигладаг. Хэрэглэгч session амжилттай дуусгасны дараа credit авах бөгөөд уг credit-ийг өөр хэрэглэгчээс суралцахдаа ашиглах боломжтой. Мөн хэрэглэгч бүр өөрийн credit-ийн үлдэгдэл болон гүйлгээний түүхийг харах боломжтой.

SkillSwap нь суралцагч, багш болон администратор гэсэн үндсэн хэрэглэгчийн үүргүүдийг дэмждэг. Администратор нь системийн үйл ажиллагааг хянах, хэрэглэгчдийн мэдээлсэн асуудлыг шалгах, шаардлагатай тохиолдолд шийдвэрлэх болон системийн audit мэдээллийг харах боломжтой.

Энэхүү төсөл нь backend болон веб интерфэйсээс бүрдэх бөгөөд Node.js ашиглан хэрэгжүүлсэн. Өгөгдлийг demo зориулалтаар санах ойд хадгалдаг тул серверийг restart хийх үед өмнөх мэдээлэл устдаг. Мөн системийн үндсэн үйл ажиллагааг шалгах автомат тестүүдийг хэрэгжүүлсэн.

SkillSwap-ийн веб интерфэйс нь хэрэглэгчдэд ур чадвар хайх, профайл харах, session үүсгэх, session-ийн явцыг хянах, credit болон мессежээ удирдах зэрэг үйлдлийг нэг дор хийх боломжийг олгодог. Ийнхүү SkillSwap нь хэрэглэгчдийн хооронд мэдлэг, ур чадварыг харилцан солилцох үйл явцыг нэг платформд төвлөрүүлсэн энгийн бөгөөд ашиглахад хялбар систем юм.
